# Команде — окружение готово, подключаемся

Всем привет. Окружение под хакатон готово и настроено — база и деплой уже работают,
каждому нужно только поставить пару вещей и вставить один промт агенту.

## Что уже сделано (не надо трогать)

- **Общий репозиторий:** https://github.com/walklikeaman/codex-hackathon-starter
- **Supabase** (база + авторизация) — общий проект команды, поднят.
- **Vercel** — привязан к репозиторию: любой пуш ветки автоматически деплоится в веб.
  Живое приложение уже открывается: https://codex-hackathon-starter.vercel.app
- Ключи Supabase вшиты в репозиторий — вписывать ничего не нужно.

## От тебя — один раз

1. **Скинь свой GitHub-ник** сюда в чат — добавлю тебя в репозиторий, чтобы ты мог пушить.
2. Поставь **Node 22+** (nodejs.org) и **Codex**: `npm install -g @openai/codex`, потом `codex` (вход под OpenAI).

## Дальше всё делает агент — открой Codex и вставь этот промт:

```
Ты — мой агент настройки окружения. Выполни всё автономно и отчитайся в конце.

1. Склонируй репозиторий https://github.com/walklikeaman/codex-hackathon-starter.git и зайди в его папку.
2. Запусти ./setup.sh — поставит CodeGraph, подключит его к Codex и положит скиллы (/ship, /loop-*, /autopilot, /pitch, /ui-polish, /schema) в ~/.codex/prompts.
3. Запусти ./scaffold.sh — поставит зависимости приложения и создаст .env.local с общими ключами Supabase.
4. Запусти npm run dev — приложение поднимется на http://localhost:3000.
5. Прочитай AGENTS.md, TASKS.md и TEAMWORK.md — правила, доска задач и как мы работаем командой.
6. Отчитайся: что готово. НЕ создавай таблицы в базе, пока мы не зафиксируем идею.

После подключения CodeGraph напомни перезапустить Codex.
```

Полная инструкция со скринами: **https://walklikeaman.github.io/codex-hackathon-starter/**

## Как работаем вместе

- Каждый — в **своей ветке** (`feature/…`), в `main` сводит один человек через Pull Request.
- На кикоффе фиксируем идею и один демо-путь (заполним блок «Проект» в `AGENTS.md`),
  режем демо-путь на куски, разбираем по себе (доска — `TASKS.md`, роли — `TEAMWORK.md`).
- `/autopilot` — веди свою задачу до зелёного сам, `/ship` — сохранить и запушить.

Вопросы по установке — сюда в чат.
