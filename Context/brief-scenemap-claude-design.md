# Дизайн-хэндовер для Claude — SceneMap

> Вставь этот бриф в Claude целиком. Задача Claude — спроектировать UI/UX
> приложения: экраны, состояния, визуальный язык. Код и данные — не твоя
> забота, их делает другая команда; твой выход — дизайн, по которому они
> соберут фронт за несколько часов.

## Роль

Ты — продуктовый дизайнер. Спроектируй mobile-first веб-приложение SceneMap:
4 ключевых экрана + состояния, единый визуальный язык, готовые макеты
(HTML/CSS или высокодетальные мокапы), по которым фронтендер сверстает
без догадок.

## Продукт в одном абзаце

SceneMap — карта мест из твоих любимых фильмов. Выбираешь свои фильмы —
карта города зажигается точками, где снимались их сцены. Кликаешь точку —
видишь кадр из фильма и это же место сегодня, читаешь, что происходило в
сцене. Отмечаешь несколько точек — приложение строит пеший маршрут
«кино-прогулку», по которому можно реально пройти и снять такие же кадры.

## Контекст использования (важно для дизайна)

- **Хакатон, демо со сцены**: приложение покажут с телефона на проекторе
  за 2 минуты. Каждый экран должен читаться с задних рядов: крупные
  постеры, контрастные пины, минимум мелкого текста.
- **Mobile-first веб**: базовый вьюпорт ~390px, открывается в браузере
  телефона. Десктоп — просто шире, без отдельной раскладки.
- Пользователь — киноман-путешественник: приехал в город и хочет увидеть
  «свои» фильмы вживую.

## Демо-сценарий (сквозной поток, который дизайним)

1. **Онбординг-выбор** → 2. **Карта с пинами** → 3. **Карточка локации** →
4. **Маршрут**. Один линейный поток, без ветвлений.

## Экраны

### 1. Выбор фильмов («зажги свою карту»)

- Сетка постеров популярных фильмов (2–3 колонки), мультиселект тапом —
  выбранный постер получает янтарную рамку и галочку.
- Сверху поиск, снизу sticky-кнопка «Показать на карте (N)».
- Вторичная ссылка: «или загрузи свой Letterboxd-экспорт (CSV)».
- Состояния: пусто выбрано (кнопка неактивна), 3–5 выбрано.

### 2. Карта города

- Полноэкранная тёмная карта (Лондон). Пины — миниатюры постеров в рамке-
  «кадрике» или янтарные метки; кластеры где точек много.
- Сверху компактный чип-бар выбранных фильмов (можно снять фильтр).
- Снизу плавающая кнопка «Маршрут (N)» — появляется, когда в корзине ≥2 точек.
- Состояния: загрузка пинов, «в этом городе точек нет — попробуй Лондон».

### 3. Карточка локации (bottom-sheet поверх карты)

Главный экран, тут вау-момент:

- Шапка: backdrop фильма во всю ширину, поверх — название фильма + год.
- Пара «тогда / сейчас»: два фото рядом (кадр из фильма ↔ то же место
  сегодня), один свайп/таб для сравнения.
- Название локации + адрес, 1–2 предложения: что за сцена здесь снималась.
- Кнопки: «Добавить в маршрут» (первичная), «Открыть в картах» (вторичная).
- Состояния: описание сцены грузится (скелетон 1–2 сек — его пишет AI),
  нет фото «сейчас» (показываем только кадр).

### 4. Маршрут «кино-прогулка»

- Карта с яркой линией маршрута и нумерованными остановками 1-2-3.
- Снизу — горизонтальная лента карточек-остановок (постер + название места),
  итог: «3 остановки · 4,2 км · ~55 мин пешком».
- Кнопка «Поделиться» (шер-картинка маршрута — если успеем).

## Визуальное направление

- **Настроение: ночной кинозал.** Тёмная карта и фон (почти чёрный,
  с тёплым подтоном), акцент — янтарный/золотой «свет прожектора».
- Карточки — как кадры плёнки: скруглённые прямоугольники с тонкой светлой
  рамкой, перфорация плёнки как декоративный мотив (умеренно, не китч).
- Типографика: выразительный дисплейный шрифт для названий фильмов,
  спокойный гротеск для UI; крупные кегли — читаемость с проектора.
- Фото и постеры — главные носители красоты; UI вокруг них тихий.
- Motion: мягкое «зажигание» пинов при первом показе карты (стагер),
  bottom-sheet с пружинкой. Уважать prefers-reduced-motion.

## Мок-контент для макетов (реальный, не lorem)

Город — Лондон. Используй в макетах эти локации:

| Фильм | Локация | Сцена |
|---|---|---|
| Notting Hill (1999) | The Travel Book Co., 13 Blenheim Crescent | книжный магазин Уильяма |
| Harry Potter (2001) | King's Cross, платформа 9¾ | проход сквозь стену на платформу |
| Paddington (2014) | Paddington Station | медведь на вокзале с чемоданом |
| Sherlock (2010) | 187 North Gower St («221B Baker St») | дверь квартиры Шерлока |
| Bridget Jones (2001) | Royal Exchange / Cornhill | финальный поцелуй на снегу |

Маршрут для экрана 4: Notting Hill → Paddington → «221B» (3 остановки, ~4 км).

## Что НЕ дизайнить

- Авторизацию, профили, настройки — их нет в MVP.
- Ленты, лайки, комментарии, любую социальность.
- Экраны книг (вторая очередь после хакатона).
- Десктопную отдельную раскладку.

## Выход

1. Макеты 4 экранов + ключевые состояния (mobile 390px).
2. Мини-система: палитра (токены), типографика, кнопки, чипы, пин, карточка.
3. Если делаешь в HTML/CSS — статичные страницы с мок-данными из таблицы
   выше, которые фронтендер переносит в Next.js как есть.
